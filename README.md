# FeastOS 🍔

FeastOS is a food delivery management system developed as a college project. It combines food ordering features with Operating System and DBMS concepts.

## Objective

To develop a food delivery system that demonstrates the practical use of Operating System and DBMS concepts.

## Features

- Browse restaurants and food items.
- Search and select food.
- Add items to cart.
- Place orders.
- User signup and login.
- View order history.
- Get food recommendations.
- View delivery routes.

## Technologies Used

- C
- PostgreSQL
- Electron
- React.js
- HTML, CSS and JavaScript

## OS Concepts

- FCFS Scheduling
- Priority Scheduling
- Resource Allocation
- Banker's Algorithm
- Deadlock Prevention

## DBMS Concepts

- Database Management
- SQL Queries
- CRUD Operations
- Transactions
- Commit and Rollback

## How to Run

1. Install Node.js and PostgreSQL.
2. Open the project folder in the terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Set up the PostgreSQL database using the provided SQL files.
5. Start the application using the provided startup script.
